## ✨ Overview

Game-AI-Assignment-2 is a comprehensive Unity development framework that combines robust dependency management, performance optimization, and high-fidelity visual assets to streamline complex scene creation and AI-driven features. It supports scalable, modular development with tools for environment setup, input handling, and rendering enhancements.

**Why Game-AI-Assignment-2?**

This project aims to facilitate efficient, reliable, and visually impressive Unity applications. The core features include:

- 🧩 **🔒 Dependency Locking:** Ensures consistent environments with detailed package manifests.
- 🚀 **⚙️ Scene Optimization:** Implements occlusion culling and rendering settings for smooth performance.
- 🎮 **🕹️ Mobile Input:** Provides virtual joystick and touch controls for seamless mobile gameplay.
- 🎨 **🌅 Visual Fidelity:** Integrates HDR skyboxes, custom shaders, and environment prefabs for immersive scenes.
- 🛠️ **🧰 Asset Management:** Offers modular prefabs and editor tools to streamline scene assembly and asset reuse.
- 🔧 **🖥️ Development Support:** Includes configuration files and scripts that enhance workflow and project stability.
